Product Deep-Dive

An 8-page system for
agent operations.

Built for teams that live in the terminal — and those who don't.

The GSD Dashboard organizes your multi-agent workflow into eight purpose-built pages. Each page maps to a core operational concern: fleet health, task execution, knowledge retention, scheduling, agent configuration, documentation, protocol plumbing, and system preferences.

Whether you're debugging a stalled agent session, reviewing a week of project output, or onboarding a new team member, the nav rail puts every surface one click away. No buried menus, no modal hell — just clean, hierarchical navigation designed for daily use.

  • Fleet — Live agent status & session telemetry
  • Tasks — Kanban boards & Gantt timelines
  • Knowledge — Notes, docs & semantic search
  • Calendar — Event timeline & ACMI sync
  • Agents — Configure and spawn new agents
  • Docs — Protocol specs & runbooks
  • ACMI — Protocol monitor & event log
  • Settings — Account, team & deployment

FAQ

Common questions.

ACMI — the Agent Communication & Machine Intelligence protocol — is an open standard for inter-agent communication, state management, and event logging. It provides a structured way for AI agents to share context, hand off work, and maintain persistent state across sessions. The GSD Dashboard is built on top of ACMI, giving you full visibility into every message, state change, and event in your agent ecosystem.

The dashboard connects directly to your ACMI protocol bus and agent runtimes. Every agent status update, task transition, and logged event is reflected in real time via WebSocket and server-sent events. There is no polling — the Fleet page, Calendar Timeline, and ACMI monitor all update instantly as agents broadcast their state changes through the protocol.
