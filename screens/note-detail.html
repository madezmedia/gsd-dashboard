Context Window Strategy

Each fleet agent receives a sliding window of the last 50 ACMI timeline events. For the OTA operations thread, we prepend the vessel manifest manifest checksum history and recent sync failures.

Payload Agent Design

The acmi-payload-agent runs on each vessel's edge node. It subscribes to acmi:work:ota-push-* and reconciles the on-device model index against the fleet manifest every 15 minutes.

// payload agent sync loop
while (true) {
  manifest = await fetchManifest(fleetId);
  local = await indexLocalModels();
  diff = computeDiff(manifest, local);
  if (diff.length > 0) await reconcile(diff);
  await sleep(15 * 60 * 1000);
}

Correlation ID Scheme

Every sync event carries a correlationId following sync-{fleetId}-{timestamp}. This lets us trace a single OTA push across all 12 vessels from the ACMI timeline.
